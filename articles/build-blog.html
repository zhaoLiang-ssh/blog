手把手搭建一个纯静态博客

很多人觉得做网站一定要用复杂的框架，其实不然。对于个人博客这种以内容为主的站点，一个 HTML 文件加上一点 CSS 和 JavaScript，就已经绰绰有余了。今天就用这个博客本身作为例子，说说我是怎么搭的。

项目结构

整个站点就一个清晰的目录：

blog/
├── index.html    # 首页
├── about.html    # 关于页
├── style.css     # 全局样式
├── script.js     # 交互脚本
└── articles/     # 文章目录
    ├── first-post.html
    └── build-blog.html

几个关键点

1. 统一的头部与底部

每个页面共享同样的导航栏和页脚，保证在页面间跳转时体验一致。虽然多了一些重复的 HTML，但对纯静态站点来说，简单可维护比什么都重要。

2. 深色模式

用一个「🌙」按钮切换主题。核心逻辑很简单，通过切换 body 上的一个 class 来改变 CSS 变量，再用 localStorage 记住用户的选择：

const saved = localStorage.getItem('theme');
if (saved === 'dark') {
  document.body.classList.add('dark');
}

3. 响应式布局

借助 CSS 的媒体查询和一个最大宽度容器，让内容在手机、平板和电脑上都能舒适阅读。

小提示：这个博客完全可以免费部署到 GitHub Pages 或 Vercel，几分钟就能上线，还能绑定自己的域名。

下一步

现在这个站点还很简单，你可以按需升级：加上标签页、全文搜索，或者换用 Hugo / Hexo 这类静态站点生成器管理大量文章。最重要的，是先让内容跑起来。
