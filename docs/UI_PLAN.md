# 心屿 · UI 视觉升级方案

> 主题定位：心理自助 · 治愈 · 平静。静态站无后端，UI 是第一印象也是唯一"门面"，因此视觉品质直接决定可信度与用户停留意愿。
>
> 审查范围：全部 16 个页面 + style.css（580 行）+ script.js + 线上实际渲染核查。

---

## 一、现状评估

**已经做对的（保留）：**
- ✅ 统一配色体系：鼠尾草绿 `#5f8f80` + 暖米白 `#f6f5f1`，整体是平静、治愈的基调
- ✅ 完整的浅色/深色双主题
- ✅ 组件风格统一（卡片、角标、callout、step、表单）
- ✅ 圆角化、柔和阴影、呼吸动画等细节
- ✅ 危机条、免责声明等功能性视觉均已就位

**可提升的空间：**

| 维度 | 现状问题 |
|------|---------|
| 视觉层次 | 单一绿色，hero 区较"平"，缺少视觉焦点与"治愈感"的氛围营造 |
| 色彩心理 | 可引入更贴合"安心"语义的次级色、柔和渐变、留白呼吸感 |
| 排版节奏 | 可增强行距、字号层级、块间距，提升长文阅读的舒适度 |
| 品牌记忆 | logo 只是文字"心屿"，可结合 favicon 图形强化品牌 |
| 移动端 | 导航在手机上无折叠，需优化；卡片间距可微调 |
| 对比度无障碍 | 部分 muted 文字在小字号下对比度偏低，需复核到 WCAG AA |
| 主题契合细节 | 可增加"平静"的微交互（光晕、漂移、柔和过渡） |

---

## 二、设计方向（让 UI 更契合"治愈"主题）

### 核心设计语言：**"静谧的岛屿 · 呼吸感"**

整个视觉要传达四个字：**安、静、柔、暖**。
- **安**：低饱和、不刺激的色彩，让人安心
- **静**：大量留白、克制的装饰，不喧闹
- **柔**：圆角、柔和阴影、渐变过渡，触感温润
- **暖**：米白的底色 + 一点暖色点缀（不是冷冰冰的科技感）

---

## 三、分阶段实施清单

### 阶段 A：视觉层次与"氛围"（最高价值）

**A1. Hero 区域增加治愈感氛围层**
- 在 hero 背景加**柔和的多色渐变 / 淡光晕**（纯 CSS，无图片，符合静态轻量）
  - 例：米白基底上叠加 `radial-gradient` 的淡鼠尾草色光晕，模拟"岛上的晨光"
- 给 h1 加细腻的渐变文字或居中标题的视觉层次
- 增加一个"下移提示"或呼吸泡泡作为氛围点缀（呼应正念主题）

**A2. 引入"安心绿"主色 + 次级"暖沙色"点缀**
- 保持鼠尾草绿为主色，补充：
  - `--sand: 暖沙棕` 用于分隔线、弱装饰
  - `--sky: 淡雾蓝` 用于危机条（与"平静但需注意"心理一致）
- 为"紧急求助"类元素保留但仍用暖橙 `--warn` 突出，形成三种情绪层级：
  - 平静（绿）→ 提示（雾蓝）→ 紧急（暖橙）

**A3. 卡片质感升级**
- hover 时增加 "轻微浮起 + 主色边框高亮"（而非仅阴影）
- 工具卡片角标、快捷入口统一成更精致的药丸形
- 增加 `background` 微纹理（如极淡的噪点/渐变），避免纯白过"平"

**A4. 排版节奏优化**
- 正文行高从 1.85 → 1.9（长文更舒服）
- 标题层级加大区分：h1 更醒目，正文留白更充分
- 为"数字步骤"（1. 2. 3.）增加更柔和的圆形编号样式

---

### 阶段 B：品牌与整合

**B1. Logo 品牌化**
- 把 favicon 里"屿"字的圆标图形，做进顶部栏 logo（`心屿` 前加一个小图形）
- 深/浅色主题下 logo 图形自适应

**B2. 一致性与动效统一**
- 统一所有按钮/链接/卡片的过渡时长（建议 0.2–0.3s）
- 深色主题下背景改用略带蓝调的暖黑（`#1b201e` 已不错，可微调）

---

### 阶段 C：移动端与细节

**C1. 移动端导航**
- 窄屏下导航项仍能完整显示（当前 4 项可用），但可优化为更紧凑的间距
- 可考虑在极窄屏折叠为居中排列

**C2. 触感与可点性**
- 卡片、按钮在移动端加大 padding，保证 44px 触控区
- 减少 hover-only 的信息（移动端无 hover），重要状态用颜色而非 hover 表达

---

### 阶段 D：无障碍与品质收尾

**D1. 对比度复核到 WCAG AA**
- 逐一核验 muted 文字、disabled 状态、深色模式的对比度
- 所有可读文字与背景的对比 ≥ 4.5:1

**D2. 深浅主题一致性**
- 确保两套主题下组件观感一致（卡片、角标、callout 在深色下同样清晰）

## 四、配色提案（升级版刻度）

```
浅色主题
── 底色        #F7F6F3   (更柔和的暖米白)
── 卡片        #FFFFFF
── 主色 安心绿  #5E8C7E  (呼吸感)
── 主色深      #3F6B5E
── 暖沙色      #D9C6A8  (装饰/分隔)
── 雾蓝 提示   #6E8CA8
── 暖橙 紧急   #C98A4E
── 文字        #373E3A
── 弱文字      #8A928D
── 边框        #E4E8E2

深色主题
── 底色        #1A1F1C   (带暖调的深绿黑)
── 卡片        #222926
── 主色绿      #93C2AF
── 文字        #E7EDE9
── 边框        #2F3733
```

**色彩心理依据：** 绿=安全/平静/自然，米白=温暖/纸感/治愈，雾蓝=沉静/可信，暖橙只在"紧急"时出现以唤起适度警觉——符合心理治愈站的伦理与情感基调。

---

## 五、建议实施顺序

1. **先做阶段 A**（视觉层次 + 配色刻度 + 卡片质感 + 排版）—— 这是"肉眼可感知的最大提升"
2. **再做阶段 B**（logo 品牌化 + 动效统一）
3. **最后阶段 C/D**（移动端 + 无障碍收尾）

每阶段完成后用浏览器实测，确保深色/浅色、桌面/移动都完好。

---

## 六、风险与注意

- **保持克制**：治愈主题切忌"花哨"，装饰永远服务于"平静"二字，不可过度动效
- **不影响伦理功能**：危机条、免责声明等可读性优先，不因美化削弱
- **纯静态**：全部用 CSS/少量 JS 实现，不引入图片或外部资源，保持轻量与快速
- **无回归**：改动集中在 style.css 与少量 HTML 结构，不影响已有的 16 页内容与交互功能

---

> 结语：这个站点已经有了一个"对"的底层审美。现阶段要做的不是推倒重来，而是**在正确的基调上叠加更充分的呼吸感、层次与品牌温度**——让每一个走进来的人，第一眼就感受到"这里是一个可以歇一歇的、安心的岛屿"。
