## 二、主要发现与问题

### 🔴 P1. Google Fonts 在部分网络下加载失败（最值得优先解决）

**现象**：线上实测 `Noto Sans SC / Noto Serif SC` 大量返回 `unloaded`，CSS 文件虽拉到 216KB，但因访问 `fonts.googleapis.com / gstatic.com` 源，国内网络经常失败、超时或极慢，导致：
- 页面按 `display=swap` 回退系统字体，视觉效果与设计稿不一致
- 首屏要等字体 CSS，**加载变慢、布局抖动**

**建议**：
1. **优先：移除对 Google Fonts 的强依赖**，改用方案 A 或 B：
   - 方案 A：直接用系统字体栈（已经写在 CSS 里：`"PingFang SC", "Microsoft YaHei"` 等），删除 `<link>` 外部字体请求。**零成本、最快**。
   - 方案 B：若仍想要特定字体，**自托管字体文件**到站内 `fonts/` 目录（`.woff2` 子集），与站点同源加载，快且稳。
2. 若短期想保留，至少在 `<link>` 上补 `media="print" onload` 异步加载技巧，避免阻塞。

**影响页面**：全部 13 页 + style.css。

### 🔴 P2. 缺少站内搜索与"分类/标签"体系，10 个工具不易被快速找到

**现象**：首页是 11 张平铺卡片，工具一多，"今天难受想快速找人"和"想长期系统练习"两类目的没有分流。

**建议**：
1. 首页增加**两条快捷路径**：
   - 「此刻很难受」→ 情绪急救 / 求助资源
   - 「想长期改善」→ 焦虑 / 失眠 / 低落 / 正念
2. 为每个工具页统一加 **面包屑 + 顶部返回**（现已有一致的 `back-home`，可增强为面包屑结构）。
3. 可选：纯前端站内搜索（`data/` + JS 过滤），中等工作量，放到 🟢 阶段。

### 🟡 P4. SEO 与分享元信息缺失

**现象**：全站 `<meta name="description">` 不完全，**缺少**：
- Open Graph（`og:title / og:description / og:image`）——微信/社交分享时无预览
- Twitter Card
- 网站 `sitemap.xml`、`robots.txt`（GitHub Pages 可加）
- 统一 favicon（当前无，浏览器标签页显示默认图标）

**建议**：
1. 首页 + 各工具页补 `og:` 标签（公益心理站的分享传播价值高）。
2. 增加 `favicon.ico`（可用温和的心/屿 SVG）。
3. 增加 `sitemap.xml` + `robots.txt`（GitHub Pages 直接放根目录）。

### 🟡 P6. 无障碍细节（WCAG）提升

**建议**：
1. 危机提示条增加 `role="alert"` 或 `aria-live`，让读屏软件优先读出。
2. 互动表单（想法记录、行动空间）的 label 已基本用 `<label>` 关联，补充 `aria-describedby` 提示。
3. 颜色对比度抽检（深色模式下的 muted 色 `#9aa49e` 在部分背景上的对比度需复核）。
4. 焦点样式（`:focus-visible`）目前依赖浏览器默认，建议统一定制高可见的焦点框，方便键盘用户。

---

**建议**：

3. 为 `style.css`、`script.js` 适当关注缓存策略（GitHub Pages 默认 ETag 已可，无需手动）。

## 四、验证方式建议

- 每次改动后用**浏览器实测**（本方案即用浏览器渲染验证过 P1 字体与各页功能）。
- 改字体/元信息后，用 Lighthouse 或简单检查：`document.fonts`、`og:` 标签、`viewport` 横向溢出。
- 改热线/内容后，复核"请以官方实时为准"提示到位。

## 五、结语

当前网站已具备**完整的 11 模块闭环 + 伦理安全底线**，基础非常扎实。本方案聚焦三件"花小力气、换大收益"的事：
1. **解决字体加载问题**（最影响观感与速度）
2. **补齐 SEO/分享元信息**（最影响公益传播与触达）
3. **优化首页分流与无障碍**（最影响真实用户使用体验）

建议先做第 1 轮（字体 + SEO + 热线提示），再做第 2 轮（分流 + 无障碍）。每一项都可在约定优先级下单独立项执行。
